# Steam Game Importer – English Edition

A native Windows application for discovering non-Steam games, reviewing SteamGridDB artwork, and adding the games to the Steam library.

## Quick start

1. Extract the ZIP archive and start `SteamGameImporter.exe`.
2. Select a game folder and click **Scan**, or use **Add manually**.
3. Enter your SteamGridDB API key at the bottom if you want cover, background, and logo artwork.
4. Select the games to import and click **Add to Steam**.
5. Review the automatically selected artwork and change it if necessary.
6. Fully exit Steam when requested, complete the import, then start Steam again.

See `USER_GUIDE_EN.md` for the complete instructions and API-key setup.

The application creates timestamped backups in `Steam\userdata\<user>\config\SteamGameImporter_Backups`. It does not download or install games.
